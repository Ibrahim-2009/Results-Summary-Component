# Results Summary Component

Results summary component Frontend Mentor Challenge

## 🚀 Overview

This project focuses on building a visually structured results summary card, combining a score overview section with a detailed breakdown of categories.

## 🛠️ Built With

* HTML5: semantic layout using sections and main
* CSS3: Flexbox + Grid for layout
* CSS: variables for consistent theming
* Google Fonts: Hanken Grotesk Font

## 🎯 Features

* Two-panel layout (Results + Summary)
* Gradient backgrounds for visual hierarchy
* Dynamic category cards with color coding
* Interactive button hover effect
* Fully responsive design for mobile devices

## 📚 What I Learned

* Combining Flexbox and CSS Grid in one layout
* Working with gradients for modern UI design
* Structuring more complex components
* Improving responsive design for multiple screen sizes
* Managing large CSS codebases using variables
